# 🎬 Netflix & Indian Content Analysis Dashboard

## 📌 Project Description

This project focuses on analyzing Netflix data along with Indian movies and web series to understand content trends, user preferences, and popular genres. The main goal of this project is to explore the data, clean it, visualize it, and build an interactive dashboard that makes the analysis easy to understand.

First, the Netflix dataset was loaded and cleaned by handling missing values, converting date formats, and organizing the data properly. After that, a separate dataset of Bollywood movies was added to focus more on Indian content. Both datasets were used to extract meaningful insights.

The project mainly highlights Indian movies and web series, especially recent content. It filters data based on country (India) and release year to analyze modern trends. A “favorite” category was also created based on ratings to compare high-rated content with other content.

Different types of visualizations were created such as:

* Bar charts to compare Movies vs TV Shows
* Line charts to show content growth over years
* Genre distribution charts to identify popular categories
* Comparison graphs for favorite vs non-favorite content

An interactive dashboard was built using ipywidgets, where users can:

* Filter content by type (Movie or TV Show)
* Select year range using a slider
* Filter favorite content

This makes the project dynamic and user-friendly instead of just static graphs.

## 🎯 Key Objectives

* Understand Netflix content trends
* Analyze Indian movies and web series
* Compare popular vs less popular content
* Build an interactive data dashboard

## 🧠 Insights Gained

* Movies are more common than TV shows on Netflix
* Indian content has increased significantly after 2018
* Drama and Action are the most popular genres
* Higher-rated content is often marked as favorite

## 🛠️ Tools & Technologies Used

* Python
* Pandas (Data Cleaning & Analysis)
* Matplotlib & Seaborn (Visualization)
* Jupyter Notebook
* ipywidgets (Interactive Dashboard)

## 🚀 Conclusion

This project demonstrates how raw data can be transformed into meaningful insights using data analysis techniques and visualizations. It also shows how interactivity can improve user experience in data analysis projects.
